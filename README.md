# Portfolio - Tehnologii Web

Acest repository conține o colecție de proiecte JavaScript și Node.js.

## Structura Proiectelor

### 1. Javascript-Basics
Proiect de bază care implementează algoritmi de compresie și criptare:
- **RLE (Run-Length Encoding)**: Algoritm de compresie simplu.
- **Caesar Cipher**: Algoritm de criptare prin substituție.
- Include teste unitare pentru validarea algoritmilor.

### 2. Javascript-Advanced
Un motor simplificat de randare a template-urilor HTML:
- Implementează funcții de parsare și randare a unei structuri de date în HTML.
- Gestionează substituția de variabile și atribute.

### 3. Restful-APIs
API RESTful construit cu Express.js și Sequelize (SQLite) pentru gestionarea unui sistem de restaurante:
- Operații CRUD pentru restaurante, meniu și adrese.
- Validarea datelor de intrare.
- Sortare și filtrare.

### 4. React-Redux
Aplicație React care utilizează Redux pentru managementul stării:
- Gestionarea unei liste de task-uri.
- Implementare acțiuni și reduceri Redux.

### 5. Small-Scripts
O colecție de scripturi mici și exerciții pentru recapitularea conceptelor de bază JavaScript (funcții, arrow functions, array manipulation).
